# Lars-Win-AI

Dream-Workflow für AI-Assistenten unter Windows — kontrolliert installierbar,
ohne AutoHotkey-Abhängigkeit.

Der vollständige Plan steht in [`PLAN.md`](PLAN.md).

## Kurzüberblick

- Globaler Hotkey **`Alt + ^`** toggelt ein Alacritty-Fenster, in dem Herdr läuft.
- Der Hotkey fokussiert gezielt das designierte **opencode**-Panel.
- **Neovim (LazyVim)** als Editor, **CaskaydiaCove Nerd Font**, transparentes,
  randloses Alacritty.
- Automatische Installation von Herdr, Alacritty, Neovim, Font, MCPs
  (Playwright, Exa) und dem Herdr-Skill.
